# FocusTrack

Mobile-first Focus & Time Tracker.

## Run
Open `index.html` directly, or deploy the repository with GitHub Pages.

## Features
- Multiple timers
- Start / Pause / Resume / Stop / Reset / Complete
- Timestamp-based accurate timing
- Active and paused duration
- Pause count
- Custom names and notes
- 25/50/60 minute quick presets
- Search/filter history
- Focus statistics
- Notifications
- Dark mode
- LocalStorage persistence
- PWA manifest/service worker
